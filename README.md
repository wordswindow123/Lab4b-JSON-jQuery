# Lab 4b – JSON and jQuery

## Description
This project demonstrates how to create and retrieve JSON data using JavaScript and manipulate HTML elements using jQuery.

## Files
- `books.json` – Contains information about two books.
- `books.html` – Retrieves and displays book information using the JavaScript Fetch API.
- `jquery-dom.html` – Demonstrates DOM manipulation using jQuery.

## Technologies Used
- HTML
- JavaScript
- JSON
- jQuery 4.0.0
