Lab 4b – JSON and jQuery

 1. Description

This project demonstrates how to create and retrieve JSON data using JavaScript and manipulate HTML elements using jQuery.

 2. Project Files

 books.json
Contains information about two books, including:
- Book title
- Author
- Publication year
- Genres

books.html
Uses the JavaScript Fetch API to retrieve data from books.json and display the book information on a webpage.

 jquery-dom.html
Demonstrates DOM manipulation using jQuery, including modifying HTML elements and handling user interactions.

 3. Technologies Used

- HTML5
- JavaScript
- JSON
- jQuery 4.0.0
- Visual Studio Code
- Google Chrome
- Live Server Extension

4. Setup Instructions

1. Download or clone this repository from GitHub.
2. Open Visual Studio Code.
3. Open the downloaded project folder.
4. Make sure the following three files are in the same folder:
   - books.json
   - books.html
   - jquery-dom.html
5. Install the Live Server extension if it is not already installed.
6. Right-click books.html and select Open with Live Server.
7. Check whether the book information is displayed correctly in the browser.
8. Open jquery-dom.html using Live Server to test the jQuery DOM manipulation features.
